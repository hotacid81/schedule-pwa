# 일정 도우미

폰 안에 할 일과 일정을 보관하는 설치형 웹앱입니다. 받은 글이나 캡처에서 날짜·시간·제목을 찾아 제안하며, 사용자가 확인한 항목만 저장합니다. 한국어 화면, 모바일 우선, 시스템 다크 모드를 지원합니다.

## 실행

이 저장소의 루트에서 실행합니다. 빌드·npm 설치가 필요 없습니다.

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

브라우저에서 <http://localhost:8080/projects/schedule-pwa/>를 엽니다. 또는 이 폴더에서 같은 명령을 실행하고 <http://localhost:8080/>를 엽니다. `file://`로 열면 ES 모듈·서비스 워커가 작동하지 않습니다. Python 서버는 개발용이며 실제 앱은 정적 파일만 필요합니다.

```powershell
node --test projects/schedule-pwa/tests
```

앱 폴더에서는 `node --test tests/`로 실행합니다. `package.json`은 ES 모듈 지정만 하며 npm 의존성이 없습니다. `tests/index.js`는 Node 24에서 디렉터리를 명시한 시험 명령도 실행되도록 하는 진입점입니다. 합성 문장만 사용하며 기준 날짜를 고정합니다.

브라우저 회귀 시험 스크립트도 외부 의존성이 없습니다. 정적 서버가 실행된 상태에서 다음 명령을 실행합니다. 새 임시 프로필의 headless Chrome을 사용하며 사용자 프로필은 건드리지 않습니다. `CHROME_PATH`와 `APP_URL` 환경 변수로 실행 파일/시험 주소를 바꿀 수 있습니다. 임시 프로필은 OS 임시 폴더에 남습니다. 시험을 마쳐도 이 폴더를 재사용하지 않습니다.

```powershell
node projects/schedule-pwa/tests/browser-smoke.mjs
```

이 세션에서는 브라우저 GPU 프로세스가 접근 거부 코드로 종료되어 화면 시험을 끝내지 못했습니다. 이 스크립트는 재실행용이며 통과했다고 보증하지 않습니다. Playwright 기반 T4와 실제 폰 설치·공유 시험은 Claude 검토 시 함께 확인해야 합니다.

## 휴대전화 설치

1. 이 폴더의 파일을 그대로 HTTPS 정적 호스팅의 원하는 하위 폴더에 올립니다. 경로·모듈·아이콘·서비스 워커는 해당 폴더 기준 상대 경로입니다. 공개 업로드는 이 구현에 포함되지 않습니다.
2. 갤럭시 S26에서 그 HTTPS 주소를 Chrome 또는 Samsung Internet으로 엽니다.
3. 앱의 우측 메뉴 → 앱 설치, 또는 브라우저 메뉴 → 앱 설치 / 홈 화면에 추가를 선택합니다. 메뉴 이름과 공유 지원은 브라우저 버전에 따라 다릅니다.
4. 최초 온라인 방문에서 서비스 워커가 준비된 뒤에는 할 일·일정·붙여넣기·백업을 오프라인으로 사용합니다.

휴대전화에서 PC의 `http://192.168.…` 주소로 접속하는 방식은 보안 컨텍스트가 아니어서 PWA 설치와 서비스 워커 시험에 적합하지 않습니다. PC의 `localhost`는 개발 예외입니다. 단순 HTTP 화면 실행과 휴대전화 설치는 구분해야 합니다.

## 사용

- **할 일:** 추가·수정·삭제·완료, 선택 마감일과 메모.
- **일정:** 날짜·시간·제목·메모 CRUD, 오늘/다가오는(오늘 포함)/지난 날짜순 보기.
- **찾기:** 글 붙여넣기 또는 이미지 선택 → 제안의 날짜·시간·제목 수정 → 일정/할 일에 추가 또는 버리기. 시간 미정은 종일로 내보냅니다. 원문은 일반 일정 메모에 자동 복사하지 않습니다.
- **공유:** 설치 후 다른 앱에서 글이나 캡처를 ‘공유 → 일정 도우미’로 보냅니다. 서비스 워커가 POST를 받아 IndexedDB 임시함에 보관하고 찾기 화면으로 연결합니다. 확인 전 일정은 저장하지 않습니다. 공유 원문은 ‘공유 원문 지우기’로 삭제할 때까지 남아 재시도할 수 있습니다. 이미지 한 번에 5장, 장당 15MB 이하.
- **내보내기:** 일정 카드의 구글 캘린더 링크를 사용자가 눌러 외부 사이트로 이동하거나 `.ics` 파일을 내려받습니다. 링크를 누르면 제목·날짜·메모가 Google로 전달됩니다. 시각이 있는 일정은 1시간 길이, 기기 현지 시간대 기준입니다. ICS는 현지 부동 시각이므로 다른 시간대에서 가져오면 그 지역 시각으로 해석됩니다.
- **백업:** 우측 메뉴에서 JSON 내보내기/가져오기. 기존 기록에 병합하고 동일 ID는 갱신합니다. 파일 전체를 검증하고 한 트랜잭션으로 저장합니다. 공유 임시함과 이미지는 백업하지 않습니다. 백업에는 제목과 메모가 그대로 담깁니다.

## OCR과 네트워크

이미지를 선택하거나 공유받아 실제 인식을 시작할 때만 Tesseract.js **5.1.1**을 불러옵니다. 유일한 외부 실행 라이브러리이며 외부 자원 출처는 `cdn.jsdelivr.net` 하나입니다. OCR 실행에 필요한 worker·WASM 코어(5.1.1)와 한국어·영어 언어 자료(`@tesseract.js-data/{kor,eng}@1.0.0`)도 같은 CDN의 고정 URL에서 받습니다. OCR은 JS 한 파일만으로 실행할 수 없어 이 부속 자원도 필요합니다. 기본 언어 URL의 가변 버전을 피하려고 고정 URL 바이트를 직접 전달합니다.

이미지 자체와 인식 글은 서버로 전송하지 않습니다. CDN에는 자료 다운로드 요청에 따른 IP 등의 일반 접속 정보가 전달됩니다. 앱 첫 화면·글 붙여넣기는 외부 요청이 없습니다. Google 링크는 사용자가 누를 때만 이동합니다.

서비스 워커가 제어하는 상태에서 받은 OCR 코드·자료는 별도 캐시에 보관하고 언어 자료는 엔진의 IndexedDB에도 저장합니다. 최초 인식은 온라인이 필요하며 기기 성능에 따라 오래 걸립니다. 캐시 삭제·용량 회수·첫 페이지가 아직 서비스 워커에 제어되지 않는 경우에는 다시 온라인 다운로드가 필요할 수 있습니다. 처음 성공한 뒤에도 모든 환경의 오프라인 OCR을 보장하지 않습니다. 실패 시 안내하고 붙여넣기를 대안으로 제공합니다.

참고: [Tesseract.js v5.1.1 API](https://github.com/naptha/tesseract.js/blob/v5.1.1/docs/api.md), [언어 데이터 로딩 원문](https://github.com/naptha/tesseract.js/blob/v5.1.1/src/worker-script/index.js), [라이선스 Apache-2.0](https://github.com/naptha/tesseract.js/blob/v5.1.1/LICENSE.md). 언어 데이터 패키지의 MIT 고지는 CDN 패키지에 포함됩니다.

## 한계와 보관

- 서버·계정·AI API·동기화·푸시 알림·다른 앱 화면 자동 읽기는 없습니다.
- 규칙 기반 제안은 오인식할 수 있습니다. 이번 주는 월요일 시작, 요일만 있으면 오늘 포함 가장 가까운 날, 오전/오후 없는 1~6시는 오후로 추정하고 경고합니다. 연도 없는 월/일이 지나면 내년으로, 일만 있으면 지난 날은 다음 달로 봅니다. 잘못된 날짜는 제안하지 않습니다. 괄호 요일 불일치는 경고합니다.
- 날짜가 없는 시간만으로는 제안하지 않습니다. 범위·반복 일정·‘다음 달’ 등의 복잡한 표현과 문맥별 취소 판정은 지원하지 않습니다. 한 줄의 다중 날짜는 분리하지만 한 날짜의 여러 시각을 별도 일정으로 만들지는 않습니다.
- IndexedDB는 브라우저/기기/주소/하위 경로별로 분리됩니다. 브라우저 데이터 삭제·앱 삭제·저장 공간 회수 시 데이터가 사라질 수 있으니 JSON 백업을 보관하세요. 암호화 백업은 지원하지 않습니다.
- Android 설치 및 OS 공유 선택기는 실제 S26에서 추가 확인해야 합니다. 모든 브라우저가 Web Share Target을 지원하지 않습니다. 서비스 워커가 활성화된 설치 앱에서만 POST 수신이 가능합니다. 업데이트는 모든 앱 창을 닫고 다시 열면 적용됩니다(앱 셸 변경 시 `sw.js` 캐시 버전도 올리세요).
- 교차 검토는 Claude가 별도로 수행합니다. 시험 결과와 미확인 항목은 `tests/verification.md`에 기록합니다.
